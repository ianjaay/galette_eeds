# Release R8 - Documents, communication and portals

## Objective

Publish controlled resources and, only after separate approval, provide
approved member, youth or guardian access.

## Scope

- Institutional document library and versions
- Audience and publication status
- Targeted announcements and notifications
- Approved member portal features
- Optional youth/guardian portal features
- Download and notification audit

## Dependencies

- R1 identity and scope
- R6 safeguarding inputs if participation features are included
- Guardian verification and youth privacy policy
- Retention, consent and communication policy
- Accessibility and mobile validation

## Exit criteria

- Publications have approved audience and retention rules
- Youth/guardian accounts expose only verified and authorized data
- No unsupervised adult-to-youth private communication
- Downloads and notifications are logged
- Supported browser, mobile and accessibility checks pass
