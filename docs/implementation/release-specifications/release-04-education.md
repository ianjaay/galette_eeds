# Release R4 - Education and progression

## Objective

Record approved branch educational progression and validation.

## Scope

- Configurable branch framework
- Objectives, stages and competencies
- Evidence and validator workflow
- Badges, distinctions and jeegos
- Historical progression across affiliations
- Adviser/educational-counsellor scope

## Dependencies

- R1 structure and member model
- Approved pedagogical framework and vocabulary
- Progression and badge validation rules
- Youth and adviser access policy

## Exit criteria

- Framework uses approved configurable terminology
- Evidence and validator authority are enforced
- Transfer preserves approved history
- Cross-scope youth access is denied
- No unapproved sensitive data is collected
